# Análisis InSAR y GNSS de deformación del terreno

Flujo en tres cuadernos de Jupyter para estimar la deformación superficial con series de tiempo InSAR (Sentinel-1, HyP3 y MintPy) y con estaciones GNSS, y para comparar ambas técnicas.

| Cuaderno | Contenido |
|---|---|
| notebooks/01_procesamiento_insar.ipynb | Procesamiento InSAR: red de interferogramas, series de tiempo y mapas de velocidad |
| notebooks/02_procesamiento_gnss.ipynb | Procesamiento GNSS: modelo de trayectoria, saltos por sismos y velocidades |
| notebooks/03_integracion_gnss_insar.ipynb | Integración y comparación entre InSAR y GNSS |

Los datos y los resultados no se incluyen en el repositorio por su tamaño.
